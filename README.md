# Interview projects

A branch-per-project collection of interview preparation work.

| Branch | Project |
| --- | --- |
| `BIS_Case_Study` | Portfolio credit risk Monte Carlo case study (Streamlit app) |
| `pandas-workout` | Pandas data-wrangling workbook with 59 exercises |

`main` contains only repository-level files. Switch to a project branch to work on
that project:

```bash
git switch BIS_Case_Study
git switch pandas-workout
```
